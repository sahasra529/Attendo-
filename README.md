## ❓ Problem Statement

Traditional attendance systems—manual or basic digital—are:
- Time-consuming and error-prone  
- Vulnerable to **proxy attendance**
- Lacking advanced analytics and early-warning mechanisms  

Institutions struggle to monitor attendance patterns, detect anomalies, and identify students at risk.

---

## 💡 Solution Overview

**Attendo** solves these challenges using a **time-limited QR-based attendance system** combined with **AI-powered analytics** and a **role-based admin dashboard**.

### 🔑 Key Concept
Each class session generates a **unique QR code** that is valid only for a **short time window**, ensuring secure and authentic attendance marking.

---

## ✨ Features

### 👨‍🎓 Student Module
- Secure login  
- Scan time-limited QR code  
- View attendance percentage  
- Access attendance history  

### 👩‍🏫 Teacher Module
- Generate QR codes for sessions  
- View present students for each class  

### 🛠️ Admin Module
- User management (students & teachers)  
- Attendance analytics & trends  
- Proxy attendance and anomaly detection  
- Risk prediction for low attendance  
- Secure report export and sharing
